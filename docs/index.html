Capabilities

A complete operator, not a chatbot.

A real ReAct loop: thinks, acts with tools, observes and corrects — with Manus context engineering techniques built in.

👁️

Sees

Analyzes images, screenshots, charts and photographed documents with describe_image (local vision).

🎙️

Listens and speaks

Transcribes meetings with local Whisper, answers voice messages and chats via voz.py.

🌐

Browses

Searches the web, opens a real browser (clicks, fills, extracts) and fetches pages as markdown with fetch_url.

📊

Generates real documents

Spreadsheets .xlsx, proposals .docx, presentations .pptx, PDFs and charts — real files, not just text.

📄

Reads contracts and invoices

Extracts text and tables from PDFs with read_pdf — contracts, invoices, reports.

💻

Codes and executes

Native Python and shell, file editing, and unlimited extension via MCP.

Execution modes

From quick command to scheduled operation.

Every task size has its mode — including strategies for small context windows.

01

Direct

One task, one command.

python main.py --prompt "..."
02

Voice

Speak the task; it executes and replies out loud.

python voz.py
03

Pipeline

Large tasks in phases with a clean context.

python pipeline.py --prompt "..."
04

Queue

Serial processing + cron for routines.

python fila.py add "..." && python fila.py run
05

Giant window

Free GitHub Models: up to 1M tokens of context.

python main.py --model openai/gpt-4.1-mini
06

MCP server

Become a tool for any MCP client.

python run_mcp_server.py

Planning · Reflection · Human-in-the-loop
